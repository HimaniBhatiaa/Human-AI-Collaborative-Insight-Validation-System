## ⚙️ How to Run Locally

### 1️⃣ Install dependencies

```bash id="run1"
pip install -r requirements.txt
```

### 2️⃣ Run FastAPI backend

```bash id="run2"
uvicorn api.main:app --reload
```

### 3️⃣ Run Streamlit dashboard

```bash id="run3"
streamlit run app/app.py
```
